# Изолированная диагностика официального Antigravity CLI

Это не сервер моделей и не обёртка для стороннего агента. Реальные результаты и ограничения — в [RESULTS.md](RESULTS.md).

Из корня ProviderStudio:

```
python3 gemini-bridge/official-probe/preflight.py
python3 -m unittest discover -s gemini-bridge/official-probe -p test_*.py -v
python3 gemini-bridge/official-probe/probe.py version
python3 gemini-bridge/official-probe/probe.py models
python3 gemini-bridge/official-probe/availability.py
```

`availability.py` без сетевых запросов сопоставляет сохранённый каталог CLI с наблюдениями из пользовательских скриншотов. Он не читает аккаунты и не считает наличие модели доказательством генерации. Отчёт: `results/availability-latest.json`. Снимки экрана не являются актуальной проверкой сессии.

`probe.py hydrogen` и `probe.py smoke` — фиксированные одноразовые диагностические запросы: первый к Hydrogen, второй к Flash. Они не служат вызовами модели для других программ. После сохранённого регионального отказа запуск блокируется до явного `--recheck`; этот флаг использовать только после восстановления официального доступа. Флаг не меняет регион/прокси. Модель должна присутствовать в последнем успешно обновлённом каталоге CLI; отсутствие или ошибка каталога блокирует запрос. Перед генерацией проверяются защитные настройки; включённые кредиты или ослабленные разрешения блокируют запрос. При доступном сервисе они расходуют включённую квоту; резервные AI-кредиты отключены временными настройками `smoke-settings.json`. Покупка/подключение API/смена подписки не выполняются.

`probe.py` использует отдельную рабочую папку, закрытый stdin и перехваченные stdout/stderr, не запрашивает интерактивный вход и не читает токены. Учётными данными управляет исключительно сам `agy`. Если клиент требует вход — остановиться, не извлекать секреты. CLI может сохранять свою историю и кеши; глобальные MCP/плагины не изолируются этим прототипом.

При отсутствии бинарника `download_cli.py` получает portable-копию по манифесту официального установщика и проверяет SHA512. Повторная загрузка другой версии поверх существующей запрещена. PATH и системные настройки не меняются. `inspect_install.py` только сохраняет официальный установщик для проверки, не исполняя его.

`.runtime/`, `results/`, `sandbox/` и загруженный установщик исключены из Git. Бинарник не является исходником проекта; автозапуск не добавлен. Диагностические результаты обезличиваются по распространённым шаблонам, но автоматическое скрытие не является универсальной защитой — перед передачей логов проверяйте их.

Никакие команды не переключают прокси, не вызывают покупку кредитов, не создают Cloud-проекты и не запускают старые внутренние API Code Assist.
